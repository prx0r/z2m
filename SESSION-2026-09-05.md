## Key Insight: Etsy Validation Strategy

> Don't build StarAtNight into a startup yet. Use Etsy to prove what sells.

### Etsy Economics (UK)
- Listing fee: $0.20 per item
- Transaction fee: 6.5%
- Etsy Payments (UK): 4% + £0.20 per order
- Regulatory operating fee: 0.48%
- **Total cost per sale: ~11% + £0.20**

### What to Prove on Etsy
1. Dogs sell
2. Memorial gifts sell
3. Couples sell
4. Christmas gifts sell
5. Star maps sell
6. Particular visual styles sell
7. Particular price points sell

### The Flow
```
Etsy listing → customer uploads photo → AI pipeline → POD supplier → delivery
```

### Only After Something Sells Repeatedly Do You Build Infrastructure

This is the boring-model rule:
- Validate on existing marketplace
- Prove demand with real buyers
- Only then build your own storefront
