# Ideation Playbook

Start from the sponsor's unique primitive, not from a random app idea.

Ask:
1. What agent decision currently relies on stale/unverified context?
2. What irreversible action lacks a proper authority boundary?
3. What sponsor data is expensive for every agent to rediscover separately?
4. Can sponsor data turn advisory AI into closed-loop action?
5. Can the result become a reusable machine endpoint/MCP tool?

Preferred shapes:
- **Live state:** stale -> sponsor live discovery -> verify -> changed decision.
- **Authority:** sponsor evidence -> deterministic cross-check -> block/defer/authorize.
- **Market/discovery:** sponsor inventory -> agent measurement -> recommendation -> approval -> execution -> verify.
- **Paid intelligence:** expensive research -> compact verified endpoint -> optional payment boundary.
- **Evaluation/routing:** candidate behavior -> benchmark -> selection -> receipt.

Score 0–5: sponsor causality, originality, demo clarity, agent relevance, real pain, technical depth, buildability, startup wedge, proofability. Reject sponsor causality/demo clarity/buildability below 3.
