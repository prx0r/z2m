# Rubric-to-Work Compiler

A core autonomy trick is converting vague judging criteria into build tasks.

## Example

Criterion: **Technical execution**

Bad task list:
- add more features
- improve backend

Compiled tasks:
- clean checkout works
- green CI
- sponsor error path tested
- one non-trivial state invariant
- public trace/receipt proving real execution
- architecture diagram matching deployed path

Criterion: **Sponsor integration**

Compiled tasks:
- endpoint/capability map
- removal test
- sponsor response visibly causes output change
- sponsor trace in demo
- mutable sponsor state revalidated before write
- official current API/version verified

Criterion: **Potential impact**

Compiled tasks:
- name concrete repeated decision/workflow
- explain current cost/risk/friction
- show reusable primitive, not only one UI
- describe narrow startup wedge

Criterion: **Presentation**

Compiled tasks:
- hook <=12 sec
- live behavior <=35 sec
- one transformation
- readable final outcome
- script <= official duration
- all public links incognito tested

This translation should happen before feature planning.
