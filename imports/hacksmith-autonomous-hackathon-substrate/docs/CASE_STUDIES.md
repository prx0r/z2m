# Three Canonical Case Studies

## LiveLLM — live economic state
Thesis: agents can reason correctly and still act incorrectly when economic context is stale.

Pattern: stale state -> live search/discovery -> official source -> extraction -> deterministic validation -> changed routing decision.

Reusable insight: one verified discovery can serve many downstream agents; narrow machine state is a natural API/MCP and later payment boundary.

Failure learned: a dimensionless value multiple was shown as monthly dollars. Units/formulas are demo P0s.

## ProofDesk — authority from evidence
Thesis: document understanding is not document authority.

Pattern: high-confidence facts -> deterministic cross-document contradiction -> authority withheld -> human resolution -> auditable outcome.

Reusable insight: confidence alone cannot authorize; evidence completeness and consistency are separate properties.

Failure learned: REJECT once advanced to APPROVABLE because “resolved” was confused with “accepted.” State semantics must embody the thesis.

## DomainArena — measured machine-facing identity
Thesis: the domain humans like may not be the one agents understand.

Pattern: sponsor inventory -> blind inference -> independent score -> winner -> fresh availability/price -> approval -> registration -> DNS readback -> receipt.

Reusable insight: deep sponsor use is strongest when it closes discovery-to-execution.

Failures learned: public Worker bypassed claimed approval; CI imported local-only package; Worker claimed CORE while defaulting legacy API. Public demo/backend/docs must be one product.
