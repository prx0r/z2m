# Landing Page Playbook

Above fold: sponsor/track, 4–9 word hook, one-sentence thesis, primary live-demo CTA, optional video/GitHub secondary link.

Recommended order:
1. hero
2. concrete problem / before-after
3. workflow
4. sponsor integration
5. live demo CTA
6. proof/tests/evidence
7. research only if differentiating
8. moat/startup wedge
9. limitations/built-vs-next where useful

Avoid giant menus, generic AI claims, unverified stats, stale counts and calling a credential-configured provider “live” without a successful live run.
