# Devpost / Submission Playbook

Treat submission as a standalone product surface for deliberation.

Collect early: project name, elevator pitch, project story, Built With tags, sponsor track, public repo, public video, live demo/Try It Out, screenshots, team details and declarations.

Before submission, open every link incognito/private. Confirm no accidental login requirement, video plays, demo loads, repo is public, README links work, no localhost URLs, correct sponsor selected, and the project is actually **submitted**, not only saved.
