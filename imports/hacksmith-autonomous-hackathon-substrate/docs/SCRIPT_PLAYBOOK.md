# Script Playbook

Write from deployed UI backwards: one sentence per meaningful visible state.

Good lines are causal and quotable:
- “The agent's math was correct. Its market state was wrong.”
- “Both extractions are correct. Together they describe an unsafe transaction.”
- “The model proposes. Code validates.”
- “Measure the name. Buy the evidence-backed winner. Verify the infrastructure.”

Avoid generic “revolutionary AI-powered platform” language, superlatives, feature lists, unsupported metrics and future features in present tense.

At 145–160 wpm: 2:00 ~290–320 words; 2:30 ~360–400; 3:00 ~435–480. Because clicking/network latency consumes runtime, a 3-minute cap usually wants roughly 330–400 spoken words.
