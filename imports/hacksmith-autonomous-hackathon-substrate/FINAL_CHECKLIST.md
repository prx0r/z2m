# Final Freeze Checklist

## Rules
- [ ] deadline verified and converted to local timezone
- [ ] eligibility confirmed
- [ ] correct sponsor track
- [ ] pre-existing work/build-period rules satisfied
- [ ] mandatory technology used
- [ ] video duration valid

## Product
- [ ] one-sentence thesis without jargon
- [ ] one centerpiece transformation
- [ ] sponsor removal test proves causality
- [ ] startup wedge is concrete, not speculative sprawl

## Technical
- [ ] clean checkout tests green
- [ ] public CI green
- [ ] sponsor API/version truthful/current
- [ ] no live secrets in repo/history; exposed keys revoked/rotated
- [ ] missing evidence fails closed
- [ ] destructive writes explicitly approved or sandboxed
- [ ] fresh state recheck before writes
- [ ] idempotency for retry-sensitive actions
- [ ] readback/verification after write where possible

## Demo
- [ ] product understood <=12s
- [ ] live behavior <=35s
- [ ] sponsor acts before claimed consequence
- [ ] no dead tabs/buttons/spinners
- [ ] dry run incognito
- [ ] stable judging URL
- [ ] script fits clicking/network runtime
- [ ] final frame shows outcome/receipt

## Repo
- [ ] README demo/video/CI above fold
- [ ] concise PITCH.md
- [ ] accurate DEMO.md
- [ ] no stale cross-project root docs
- [ ] no broken links
- [ ] test claim matches CI or says “CI green”
- [ ] built/prototype/planned separated

## Submission
- [ ] video public/processed
- [ ] repo public
- [ ] live demo public
- [ ] screenshots
- [ ] Built With accurate
- [ ] correct sponsor challenge selected
- [ ] all links incognito-tested
- [ ] actually submitted, not draft

## Freeze
- [ ] no unresolved P0
- [ ] final tag/commit
- [ ] stop adding features
