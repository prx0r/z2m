# 04 — Premium Advisor Store

A config-driven high-ticket specialist store. Change `config.yaml` + `catalog.json` and the same experience can serve saunas, standing desks, massage chairs, portable power stations, espresso setups, etc.

## Run
`uvicorn app:app --reload --port 8104`

## Zero-capital sequence
1. Start affiliate/referral mode while proving organic demand.
2. Measure clicks, quote requests and actual conversions.
3. Negotiate direct dealer/dropship terms only for products that already convert.
4. Switch winning SKUs to direct-sale mode where supplier economics justify the added operational risk.

## Production work
- authorized price/feed adapters and history
- true stock/lead-time tracking
- richer advisor rules per niche
- supplier quote workflow
- checkout only after cashflow/liability design
- returns/warranty state machine
- per-product server-rendered pages + canonical URLs + schema validation
