# 30-Day Launch Plan

## Recommendation: sell Voice Concierge first, build Claims second

### Why voice first
- obvious demo value;
- current category validates willingness to pay;
- low raw infrastructure cost;
- direct fit with high-ticket ecommerce and the GeoCommerce premium-store thesis;
- can cross-sell every later specialization through the same phone/chat identity layer.

### Do not launch as “AI phone support for Shopify”
Position narrowly:

> **24/7 sales + support phone agent for high-ticket Shopify stores. It knows products/orders, texts checkout links, and hands hot buyers to a human with the entire conversation summarized.**

Target 3 verticals initially:
1. home water / filtration / utility equipment;
2. premium coffee / kitchen equipment;
3. ergonomic/home-office/outdoor equipment.

## Days 1–7
- implement live Shopify OAuth/store install;
- connect Retell first;
- connect Gorgias ticket handoff;
- build 20-call simulator covering order status, product fit, unknown spec, address change, angry customer, refund request, human transfer;
- record every outcome.

## Days 8–14
- recruit 3 design partners from stores visibly offering a phone number;
- free/cheap pilot for 14 days, but require access to call outcomes;
- benchmark human-only vs AI-first: answer rate, average handle, resolved %, transfers, sales influenced.

## Days 15–21
- verticalize the top-performing product category;
- create curated product-truth fields and troubleshooting graph;
- add “text me this product/cart” tool;
- add callback scheduler / human relay.

## Days 22–30
- charge $149–$299 base + usage;
- publish anonymized ROI proof;
- approach agencies implementing Shopify/Gorgias;
- begin claims module with one merchant that has parts/warranty pain.

## Kill criteria
Kill/reshape the wedge if after 300+ real calls:
- customers overwhelmingly refuse AI voice;
- >50% calls still need human transfer for reasons the system cannot structurally solve;
- direct gross profit after infra + support is <60%;
- merchants cannot attribute support cost reduction or sales lift.
