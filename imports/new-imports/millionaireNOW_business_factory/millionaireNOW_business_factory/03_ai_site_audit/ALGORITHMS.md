# Algorithms — AI Site Audit

## Product truth
Sell this as **AI/search visibility readiness + conversion diagnostics**, not “we know ChatGPT's ranking algorithm”. OpenAI and Google both say inclusion is not guaranteed.

The starter score is weighted:
- 25% crawlability
- 25% machine readability
- 20% trust/entity evidence
- 20% conversion readiness
- 10% freshness signals

Every point comes from observable page characteristics. Findings are more important than the single score.

## High-value upgrade
Add a controlled “buyer simulation” layer: extract only the target page's claims, then ask an LLM to answer a niche buyer question using those claims. Score whether it can correctly identify service, location, price/quote path, differentiators and next action. Never present the simulation as actual ChatGPT search ranking.

## Funnel
`free audit -> evidence-backed report -> one-click implementation quote -> monthly monitoring`.
