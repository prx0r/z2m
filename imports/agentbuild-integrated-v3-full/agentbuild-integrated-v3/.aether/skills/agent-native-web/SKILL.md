# Agent-Native Web

Expose one underlying capability through appropriate surfaces rather than building unrelated human/agent products.

For public tools, consider:
- semantic HTML and accessible form labels
- stable canonical URLs
- explicit API docs / OpenAPI for programmatic APIs
- MCP when a capability is useful to agents
- robots.txt and sitemap.xml for crawlable sites
- concise machine-readable descriptive surfaces (including llms.txt where useful), treated as discoverability metadata rather than a magic ranking signal
- clear limits, freshness timestamps and provenance for live sensor data

Never create thin duplicate pages solely to inflate search footprint.
