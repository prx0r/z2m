# Agent-Native Web Standard

1. Capability first: one canonical backend/function can serve web, REST and MCP surfaces.
2. Machine actions have explicit schemas, stable names and bounded outputs.
3. Live facts include source/provenance and observation timestamps.
4. Public sites use semantic HTML and ordinary crawlable URLs; agent support must not degrade human accessibility.
5. APIs expose machine-readable docs when useful.
6. Pricing/limits should be machine-readable where metered.
7. Never generate duplicate doorway pages merely to manipulate discovery.
8. Treat experimental agent-discovery techniques as experiments until measured.
