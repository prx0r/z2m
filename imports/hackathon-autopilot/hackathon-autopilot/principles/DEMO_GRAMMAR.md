# Demo Grammar

The canonical demo is a proof, not a tour.

## Universal transformation

```text
BAD / UNCERTAIN BEFORE STATE
        ↓
REAL EXTERNAL INPUT
        ↓
SPONSOR TECHNOLOGY
        ↓
STRUCTURED STATE / EVIDENCE
        ↓
PRODUCT-SPECIFIC LOGIC
        ↓
VISIBLE DECISION
        ↓
ACTION OR WITHHELD ACTION
        ↓
VERIFICATION / RECEIPT
```

## Memorable contrast patterns

- **Correct reasoning, stale state.**
- **Correct extraction, unsafe joint evidence.**
- **Human-preferred name, machine-misunderstood identity.**
- **Agent proposes; deterministic code validates.**
- **Recommendation autonomous; spending is not.**
- **High confidence; still blocked.**

Use contrasts because judges remember contradictions better than architecture diagrams.
