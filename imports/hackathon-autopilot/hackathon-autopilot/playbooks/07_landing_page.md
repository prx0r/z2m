# Playbook 07 — Landing Page

Above the fold:
1. product name
2. memorable one-line thesis
3. 1–2 sentence problem/value
4. Live Demo button
5. Demo Video button when available
6. GitHub link
7. sponsor track badge

Next:
- before/after or problem contrast
- pipeline
- sponsor integration
- canonical demo CTA
- proof / tests
- architecture
- research only if it directly supports differentiation
- limitations / built-vs-next
- close

The landing page is a judge compression layer, not a marketing microsite.
