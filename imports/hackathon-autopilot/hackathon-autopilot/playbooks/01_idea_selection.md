# Playbook 01 — Idea Selection

Generate 5–10 concepts.

Score each 0–5 on:
- rubric fit
- sponsor centrality
- originality
- one-demo clarity
- feasibility in remaining time
- technical depth
- startup/real-world viability
- ability to produce machine-verifiable evidence
- safe handling of irreversible actions
- reuse of existing infrastructure

Apply a **complexity penalty** for:
- many external dependencies
- unproven credentials
- mobile/native build requirements
- data acquisition not already solved
- more than one user persona
- more than one canonical demo story

## Agent-infrastructure bias
Prefer problems where an agent needs:
- current state
- trustworthy evidence
- permission to act
- economic constraints
- identity/discovery
- verified execution
- memory/observability
- evaluation/routing
- payments
- security

Only use this bias when it improves track fit.
