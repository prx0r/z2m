# Playbook 06 — Recording Script

Write for the ear, not the README.

## Script tests
- first sentence contains the user/problem or surprising shift
- sponsor named by 35 seconds
- real demo begins by 45 seconds
- one sentence explains what AI does
- one sentence explains what deterministic code/policy does
- every number is verified
- no unsupported superlatives
- no feature list longer than three items
- final line is memorable
- timing leaves 15–25% buffer for clicks/loading

## Preferred sentence pattern
Short claim.
Visible proof.
Consequence.

Example:
> "Both documents were read correctly. ProofDesk still blocks the transaction."

Avoid:
> "Our innovative platform leverages state-of-the-art AI..."
