# Playbook 03 — Build the Vertical Slice

Build exactly one scenario.

A strong vertical slice has:
- a fixed input
- a real sponsor call
- observable intermediate state
- a product-specific decision
- a meaningful consequence
- a proof artifact

Do not build:
- settings page
- account system
- generic dashboard
- secondary model provider
- extra sponsor
- broad analytics
- full marketplace
- future monetization

until the canonical path works.
