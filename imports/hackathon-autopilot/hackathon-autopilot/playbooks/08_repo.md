# Playbook 08 — Repo Organization

## README top 40 lines
Must answer:
- what is it?
- why does it matter?
- where is the live demo?
- where is the 2–4 minute video?
- which sponsor is central?
- what is the end-to-end transformation?
- what is proven?

## Recommended root

```text
README.md
PITCH.md
DEMO.md
RECORDING-SCRIPT.md
DEVPOST-SUBMISSION.md
LICENSE
.env.example
src/ or product package
tests/
docs/
archive/
```

## Archive immediately
- HANDOFF*
- HANDOVER*
- PLAN-*
- FINAL-REVIEW*
- unrelated project plans
- stale submission variants
- internal judge notes
