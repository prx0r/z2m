# Playbook 10 — Submit and Freeze

Before pressing submit:
- correct track selected
- project name final
- one-line pitch final
- video public/unlisted and accessible without login
- live demo accessible without login
- GitHub public/shared as required
- setup instructions tested
- screenshots legible
- sponsor heavy-lifting sentence present
- limitations truthful
- no secrets
- CI green
- final commit SHA recorded

After submission:
- save Devpost URL
- save final commit SHA
- save deployment URL
- save video URL
- screenshot confirmation if possible
- do not make risky changes unless submission can be safely edited
