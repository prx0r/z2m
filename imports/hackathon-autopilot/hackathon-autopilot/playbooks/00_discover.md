# Playbook 00 — Discover

Capture only official-source facts first.

## Required research
- challenge overview
- exact deadline + timezone
- rules / eligibility
- prize tracks
- required sponsor technology
- judging criteria and weights if available
- submission fields
- video length
- repository requirement
- live demo requirement
- public/private repo requirement
- sponsor docs
- rate limits / sandbox / billing / destructive actions
- advanced API capabilities
- examples from sponsor

## Deliverables
- `hackathon.json`
- `RUBRIC.md`
- `SPONSOR-DOC-NOTES.md`
- `SUBMISSION-REQUIREMENTS.md`

## Rule
Never let a third-party blog override official rules.
