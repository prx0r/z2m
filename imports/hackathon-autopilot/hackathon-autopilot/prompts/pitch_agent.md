# Pitch Agent Prompt

Write a natural hackathon pitch around one memorable inversion.

Order:
1. problem
2. surprising insight
3. what the product does
4. why sponsor is indispensable
5. proof from canonical demo
6. why it can become a product
7. close

Constraints:
- no generic "AI-powered platform" opening
- no more than 3 features in any sentence
- no fake market-size precision
- planned functionality must sound planned
- script and README must use the same thesis
