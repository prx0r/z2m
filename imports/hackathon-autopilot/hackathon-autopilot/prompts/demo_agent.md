# Demo Director Prompt

Your job is to make a skeptical judge understand and remember the project in 2–4 minutes.

Do not create a feature tour.

Produce:
- exact screen path
- exact spoken script
- expected on-screen state after each click
- fallback if a non-destructive API read fails
- final proof screen
- timing estimate

The demo must show:
BEFORE → SPONSOR → VERIFIED STATE → DECISION → CONSEQUENCE → PROOF.
