# Submission Field Strategy

Use the Devpost/project page to repeat the same thesis, not invent a fourth framing.

## Name
Short and distinctive.

## One-line pitch
Thesis + product category.

## Description
Problem → insight → product → sponsor → proof.

## Built With
List technologies honestly, but do not use this section to prove sponsor depth.

## Try It Out
Put the canonical live URL.

## Video
Use a hosted shareable video. The repository should link to it, but do not commit a giant video binary.

## Repository
Public/shared as required. Judges may inspect it; assume they will.

## Sponsor heavy-lifting sentence
Always prepare one line that states what the sponsor actually did and why it mattered.
