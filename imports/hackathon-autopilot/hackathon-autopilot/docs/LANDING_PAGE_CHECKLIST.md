# Landing Page Checklist

## Above fold
- [ ] thesis readable without scrolling
- [ ] one-sentence value
- [ ] live demo button
- [ ] video button
- [ ] GitHub
- [ ] sponsor/track

## First scroll
- [ ] concrete problem contrast
- [ ] canonical pipeline
- [ ] sponsor centrality

## Later
- [ ] proof/tests
- [ ] architecture
- [ ] safety/failure semantics
- [ ] built vs next
- [ ] limitations
- [ ] product wedge

## Avoid
- giant feature grid before demo
- research dump before product
- inflated market claims
- 10 logos in "built with"
- multiple competing CTAs
