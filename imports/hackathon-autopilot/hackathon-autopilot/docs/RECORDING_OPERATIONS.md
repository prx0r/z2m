# Recording Operations

## Pre-record
- use a lightweight recorder when hardware is constrained
- 720p / 20–30 fps is sufficient for UI demos
- close unrelated apps/tabs
- enlarge browser text enough for mobile judging
- read the script from a second device if possible
- do a 10-second audio test
- clear demo state
- verify no secrets are visible
- verify destructive actions are gated or disabled

## Recording behavior
- do not rush the hook
- let important state changes remain on screen
- move cursor deliberately
- avoid frantic scrolling
- do not narrate code unless the code itself is the sponsor proof
- if a live external call can be slow, write narration that tolerates a few seconds

## Post-record
- watch once without sound: can you infer the story?
- listen once without video: is the pitch coherent?
- verify all displayed numbers
- verify final runtime
- upload and test the video in incognito/private mode
