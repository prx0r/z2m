# Two-Demo Runbook

## Demo A — Security

1. Start HydraDB.
2. Start QDW.
3. Start Bitt's QDW module API.
4. QDW validates protocol.
5. Materialize an official BitSec DEV task.
6. Freeze `security-01/v0`.
7. Compile ContextPack.
8. Freeze BudgetEnvelope.
9. Execute through real worker runtime.
10. Save trajectory/artifacts to CAS.
11. Bitt evaluates with official evaluator.
12. Create EvaluationResult and RunReceipt.
13. Append QDW ledger events.
14. Project Hydra.
15. Verify run in QDW API/UI.
16. Generate one LearningProposal.
17. Create v1 candidate.
18. Same sealed task set, same budget.
19. Promote or reject.
20. Optional live BitSec submit only behind MW Grant.
21. Record TAO/rank separately as EconomicOutcome.

## Demo B — Ecom

1. Start QDW, Z2M module and FinalBuilds.
2. Z2M exposes a real product hypothesis/program.
3. QDW matches it to the Ecom Pool.
4. Freeze `ecom-01/v0`.
5. Use zero-spend BudgetEnvelope.
6. Request a verified artifact from FinalBuilds.
7. Publish to an approved zero-cost surface.
8. Z2M collects a fixed observation window.
9. Evaluate actual impressions/clicks/saves/orders/margin.
10. Create RunReceipt and project Hydra.
11. Generate one LearningProposal.
12. Run controlled variant.
13. Promote or reject.
14. Only then consider a tiny paid test under MW Grant.
