# Store Archetypes That Fit the Factory

The store should be selected by *decision problem*, not merely product category.

## A. Personalized Gift Engine
Examples: family annual, memory journal, card game, heirloom cookbook.

**Why it works**
- hard to price-compare;
- gift urgency;
- AI reduces bespoke production cost;
- digital/POD means little inventory risk;
- one backend can generate many recipient/occasion storefronts.

**Moat**
- structured intake
- high-quality output QA
- persistent user project
- fast previews
- gift deadlines
- reorder / annual refresh

## B. Hobby Starter Expert
Examples: needlepoint, journaling, crochet, Mahjong accessories.

**Why**
- Etsy data shows current hobby/analog demand;
- beginners want curation and instructions, not infinite SKUs;
- kit + guide + personalization lifts differentiation.

**Moat**
- beginner diagnosis
- generated project plan/pattern
- verified instructions
- compatibility / supplies list
- community examples

## C. Recipient-Native Gift Store
Examples:
- Gifts for Home Baristas
- Gifts for New Dog Owners
- Gifts for Journalers
- Gifts for Couples Who Travel

**Why**
Generic gift guides are weak. Recipient/problem-specific properties create better long-tail content and merchandising.

**Moat**
- live product availability and price
- recipient quiz
- shipping cutoff
- comparison
- personalization layer

## D. Geo-Native Specialist
Examples: Norwegian dog travel, Danish home barista, Swedish hobby gifts.

**Moat**
- language
- local payment/shipping expectations
- local returns/warranty
- actual delivery estimates
- local supplier/warehouse ranking

## E. Affiliate-First High-Ticket Expert
Examples: projectors/home cinema, espresso machines, premium pet travel.

Do not start by dropshipping a $500 object.

Start with:
- comparison
- compatibility
- buyer guides
- affiliate lead-out
- organic video
- email capture

Only become merchant when data proves a profitable SKU/market.

## Store KPI contract

Every store must expose:
- sessions by channel
- product impressions
- PDP CTR
- add-to-cart
- checkout start
- purchase
- AOV
- gross margin
- contribution before ads
- CAC
- refund/return
- shipping SLA
- support contacts/order
- organic vs paid split
- repeat rate
- personalization attach rate
- AI adviser usage and conversion lift
