# One-Page Strategy

## Build these first

### Engine 1 — Puzzle
Crossword → trivia → bingo → scavenger hunt  
**Fastest MVP. Lowest QA burden. Strong Secret Santa/Q4 fit.**

### Engine 2 — Story
Newspaper → comic → yearbook → pet book → family memoir  
**Largest gifting surface and best premium ladder.**

### Engine 3 — Decision
Renovation quote comparison → wedding vendor comparison → moving-abroad plan → golf plan → Airbnb guide  
**Best Google Ads economics because the buyer is already spending serious money.**

### Engine 4 — Wrapper
Physical card + QR + POD print  
**Turns any digital artifact into a conventional gift ritual.**

## Launch order

1. Personalized crossword — prove checkout + intake + preview + delivery.
2. Roast newspaper — prove visual personalization.
3. Relationship/pet mini-book — prove premium physical upsell.
4. Renovation quote comparator — prove high-intent Google acquisition.
5. Only then build the shared recipient/reminder graph.

## Do not overengineer

You do not need:
- an app,
- subscriptions,
- a marketplace,
- your own print facility,
- 100 templates,
- a giant agent system.

You need:
- one landing page,
- one intake flow,
- one excellent preview,
- one payment,
- one generated artifact,
- real reviews.

Then transmute.
