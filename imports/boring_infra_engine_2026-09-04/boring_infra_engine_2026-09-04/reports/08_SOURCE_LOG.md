## Research methodology caveat

TrustMRR states its revenue is verified via connected payment-provider credentials, but profile fields such as “users,” founder messages, market description and margin claims are separate metadata. This report therefore labels revenue verification separately from founder/marketing claims.

TrustMRR API documentation: https://trustmrr.com/docs/api — official API exists, but its acceptable-use language explicitly restricts cloning businesses/bulk republication. The included engine uses a curated dataset and does not automate scraping/republication.
