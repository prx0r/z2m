# Tender Qualifier + Bid Desk
Match public tenders to an SME capability profile, reject obvious no-bids deterministically, and create an evidence/checklist report. The live adapter uses Contracts Finder's documented OCDS search endpoint; manual ingest covers other portals.

Business model: free alert/match tier, paid qualification/bid concierge, or a monthly niche feed. Never claim the kernel has checked tender documents it has not ingested.
