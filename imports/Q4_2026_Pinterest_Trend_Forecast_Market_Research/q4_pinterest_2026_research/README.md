# Q4 2026 Pinterest Demand-Forecasting & Product Research Pack

Prepared: 4 September 2026

This pack turns the current Pinterest/Q4 thesis into a repeatable low-capital research system. It covers:

- how to obtain and analyse Pinterest data for free or near-free;
- how to improve the “800k views / multiple pins / multiple months” heuristic shown in the supplied Thibault Barral screenshots;
- what is rising on Pinterest now and which Q4 product families are most likely to outperform;
- how to cross-validate Pinterest demand with Etsy, TikTok, Meta, Google, Reddit and marketplace data;
- which APIs, MCP servers and operator tools are useful versus guru noise;
- a reusable forecasting model, scorecard and 30-day execution plan;
- working Python for analysing Pinterest CSV exports without paid analytics software.

## Start here

1. Read `00_EXECUTIVE_SUMMARY.md`.
2. Read `01_PINTEREST_ANALYTICS_AND_FREE_APIS.md` and use `code/pinterest_export_analyzer.py` on Pinterest Analytics CSV exports.
3. Use `02_Q4_2026_FORECAST.md` for product-family priorities.
4. Use `03_CROSS_PLATFORM_RESEARCH_STACK.md` to validate demand before spending.
5. Use `04_FORECASTING_MODEL.md` and `data/product_opportunity_scores.csv` to rank ideas consistently.
6. Execute `05_30_DAY_EXECUTION_PLAN.md`.

## Important limitation

No private Pinterest account data was available in this chat. The analysis therefore uses the supplied screenshots, official Pinterest public trend/analytics documentation, fresh September 2026 public trend snapshots, Etsy/TikTok/Meta/Google documentation and current operator discussion. The included scripts are ready for your own Pinterest exports/API token once connected.
