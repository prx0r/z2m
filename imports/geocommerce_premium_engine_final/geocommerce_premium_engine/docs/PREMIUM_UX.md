# Premium consultant-store UX

The template should feel closer to a high-end specialist showroom than a dropshipping store.

## Page sequence
1. **Intent-first hero** — what problem the category solves, not a discount timer.
2. **Guided advisor** — 4–8 questions: budget, use case, space/size, frequency, priorities.
3. **Shortlist** — best fit / premium / value, with explicit tradeoffs.
4. **Cinematic media** — exact-product orbit, use-case, detail macro; verified against reference images.
5. **Proof table** — warranty, delivery, materials, certifications, dimensions, service.
6. **Buying guide** — “what matters” content compiled from actual search vocabulary.
7. **Local checkout** — local currency, payment method expectations, duty/tax transparency and delivery choice.
8. **Human escalation** — callback/relay request for expensive or uncertain purchases.
9. **Post-purchase concierge** — tracking, setup guidance, warranty/returns.

## Advisor rules
- never make up specs;
- state uncertainty and open a human ticket;
- ask one useful question at a time;
- compare only products that pass hard compliance/supplier gates;
- optimize buyer fit, not supplier commission;
- persist questions users ask because they become new catalog fields and SEO content.

## The hidden data moat
Every customer question becomes evidence about what novice buyers do not understand. Aggregate those questions into:
- new comparison dimensions;
- new FAQs;
- new Merchant/feed attributes;
- new search-term clusters;
- supplier questions;
- product rejection rules.
