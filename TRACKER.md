# z2m Daily Tracker

## Format

Each day gets a log entry:

```
## YYYY-MM-DD

### Revenue
- Amount: $X
- Source: platform/program
- Status: submitted/accepted/paid

### Activity
- What the worker ran
- Findings produced
- Submissions made
- Clients contacted

### Stats
- Total findings: N
- Total submissions: N
- Total accepted: N
- Total paid: N
- Cumulative revenue: $X

### Notes
- What worked
- What failed
- What to do tomorrow
```
