# Competitor / Business-Model Map

| Layer | Examples | What they prove | Weakness / opening |
|---|---|---|---|
| Legacy occasion platform | Moonpig, Greetz, Funky Pigeon | Repeat occasion demand, reminders, attach gifting | Large legacy UX, broad catalogue, less niche art direction |
| Photo memory | CEWE, Snapfish, Mixbook, Popsa | Photo books/calendars are durable gifts | Creation can still feel like work |
| Personalised publishing | Wonderbly | High willingness-to-pay for emotionally bespoke outputs | More complex content + fulfilment |
| Marketplace | Etsy | Vast demand for custom/made-to-order | Fragmented UX/quality; buyer must search |
| POD infrastructure | Prodigi, Gelato, Gooten, Printify | No inventory needed; global fulfilment accessible | Commodity layer |
| Personalisation SaaS | Teeinblue, Customily, Zakeke, Kickflip | Merchants pay to add customisation + auto print files | Mostly seller tooling; consumer still “configures” |
| AI-native gift startups | YouComics, Giftimage, Tiny Stories, Book4U | “Photo/prompt → unique physical object” now works | Early/fragmented; quality and retention unclear |
| Platform threat | Amazon Alexa for Shopping custom merch | Primitive is mainstream and can be frictionless | Currently generic categories; opportunity to go deeper on gifting |

## The trap: rebuilding existing personalisation SaaS

Teeinblue, Customily, Zakeke and Kickflip already provide:
- text/photo personalisation;
- live previews;
- print-ready files;
- POD integrations;
- automated order flows;
- increasingly, AI tools.

Building another drag/drop editor is not asymmetric.

## The opening: remove design work entirely

Most existing systems ask:
> “What do you want to put on this mug?”

The better system asks:
> “Tell us about the person.”

Then it does creative direction.

### A useful product ladder

**Level 0 — template personalisation**
Name + image inserted into fixed template.

**Level 1 — AI transformation**
Turn pet/person into illustration/style.

**Level 2 — AI creative direction**
Generate concept, copy, layout and visual system from recipient context.

**Level 3 — recipient memory**
Remember who they are, tastes, past gifts, relationships and important dates.

**Level 4 — autonomous occasion commerce**
Weeks before the occasion:
“Three new ideas for Dad this year, based on what he liked last time. £18–£35. Delivery guaranteed.”

The durable value rises dramatically from L0 → L4.

## Cloneable successful patterns

### Pattern A: Moonpig
Acquire on one occasion → save reminder → return next occasion → attach gift → subscription.

### Pattern B: Wonderbly
Make the recipient the protagonist → high emotional specificity → premium physical keepsake.

### Pattern C: Etsy
Long-tail recipient/occasion queries (“first Christmas as…”, “gift for… who…”) capture high intent.

### Pattern D: CEWE
Turn photos already owned by the customer into a finished memory object; Q4 profit concentration.

### Pattern E: Amazon
Conversational idea → automatic generation → no design skill → production/delivery integrated.

### Recommended combination
**Moonpig retention + Wonderbly emotional value + Etsy long tail + CEWE memories + Amazon frictionless generation.**
