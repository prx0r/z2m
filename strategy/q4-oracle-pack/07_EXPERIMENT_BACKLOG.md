# First 30 Experiments — Ordered for a Small Treasury

## Phase 0 — no paid media

1. Generate family annual demo + landing page.
2. Create 5 Etsy-style recipient/occasion variants.
3. Create 30 Pinterest assets from the same demo.
4. Publish a personalized memory-journal digital product.
5. Publish a grandparent memory-book digital product.
6. Publish a custom family card-game demo.
7. Publish an heirloom cookbook demo.
8. Publish a personalized Advent digital product.
9. Publish an AI-personalized needlepoint-pattern demo.
10. Publish a pen-pal stationery printable.
11. Build a recipient-native gift finder for one niche.
12. Connect gift finder to affiliate products where permitted.
13. Build one Home Cinema comparison page using current product data.
14. Build one Dog Travel comparison page with compatibility fields.
15. Upload eligible owned physical/POD products to Google Merchant free listings.
16. Create Search Console and free-listing observation ingestion.
17. Create Pinterest board clusters by recipient, not generic keyword.
18. Run Etsy Marketplace Insights/manual checks for top 10 candidates.
19. Capture top-20 seller prices/reviews/result density for each.
20. Reject any candidate whose competition signal is poor unless personalization materially changes the query.

## Phase 1 — spend only from evidence

21. Buy one sample only for the best physical-lightweight candidate.
22. Produce real/consistent photos or a controlled product-render workflow.
23. Run a $10–$20 Shopping test only where break-even CPC math supports it.
24. Run a second paid test against a different offer, not a different random product.
25. Compare personalized vs generic PDP.
26. Compare specialist vs generic storefront framing.
27. Compare free-listing winners vs randomly selected control SKUs.
28. Compare Pinterest organic signal vs subsequent conversion.
29. Graduate one marketplace winner to branded specialist site.
30. Record hypothesis returns in Hydra and update admission weights.

## Kill rules

- No live competition evidence → no meaningful ad spend.
- Contribution cannot tolerate current CPC → no paid Search.
- Supplier sample poor → reject physical product.
- Delivery window too close → stop Q4 acquisition.
- Generic AI output with no visible quality advantage → reject.
- Any product requiring unsupported medical/safety claims → reject or rewrite offer.
